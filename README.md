# Mini Quest (DQ風ミニ探索ゲーム)

Next.js + TypeScript で作った、1分で遊べる簡単な探索ゲームです。ポップなドット絵風で、ドラクエっぽい操作感を目指しました。

## セットアップと起動

```bash
npm install
npm run dev
# http://localhost:3000 にアクセス
```

## 操作

- 移動: 矢印キー / WASD
- 調べる・話す・戦う: Enter / Space（対象の隣で実行）
- リセット: 画面右上の「リセット」ボタン

## ルール / 流れ

1. 村からスタート。NPC A/B/C に隣接して調べるとヒントが聞けます。
2. 村の家（武器の家）に入り、武器タイルに乗る or 隣で調べると武器を取得します（取得後はアイコンが消えます）。
3. 外Aにいる恐竜敵に隣接して調べると戦闘判定。武器なしなら「攻撃が弾かれた」、武器ありなら撃破となり道が開きます。
4. 敵撃破後、外Bへ進めるようになります（門の隣で調べる）。
5. 外Bの宝箱の隣で調べるとクリア。クリア後は入力が無効になります。

## 衝突判定

- プレイヤーは NPC / 敵 / 宝箱 / 壁 / ドア / 門のマスに侵入できません（重なり防止）。
- ドア・門は「隣接して調べる」で出入りします。
- 武器タイルは乗ることができますが、取得後は非表示になります。

## 今回の主な変更

- すべての重なりを防ぐ衝突判定を実装（NPC / 敵 / 宝箱 / ドア / 門 / 壁が遮蔽物）
- 敵を恐竜っぽいドット絵に変更し、UI/アイコンをポップなドット絵テイストに統一
- ログやステータス枠をドラクエ風のピクセル調デザインに調整
